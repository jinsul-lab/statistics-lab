# 입지자료·저장·출력 검증 — v3.8.4

검토일: 2026-10-25 (한국시간). 실제 환자 자료·인증정보·실제 병원 조회를 사용하지 않은 합성 자료 검사다.

## 확인된 결함과 수정

| 결함 | 수정 | 영향 |
|---|---|---|
| 시설의 일부 응답 상태가 `partial`에만 있으면 입지자료 저장은 `truncated`만 읽어 완전 조회처럼 보였다. | 스냅샷에 두 부분 조회 신호를 함께 보존했다. JSON 왕복·저장 HTML에도 일부 결과 표시를 유지한다. | 주차장·약국 등 확인 개수를 전체 개수로 오해하지 않게 한다. 실제 0건·조회 실패는 기존처럼 구분한다. |
| 저장 자료에서 미확인 거리 `null`이 반올림 과정에서 0m가 되고, 비교 조건에서 250m 이내로 집계됐다. | 유한한 0 이상 거리만 거리 구간에 넣는다. 표·근접 시설은 ‘거리 미확인’으로 표시하고, 차트에는 거리 확인/미확인 건수를 설명한다. 모든 거리가 미확인이면 네 구간 모두 자료 없음으로 둔다. | 위치 미확인이 후보와 같은 위치로 보이는 오류를 수정한다. 실제 0m는 정상적으로 첫 구간에 포함한다. |
| 위치 개요가 좌표 없는 기관을 제외한 뒤 번호를 다시 매겨 의료기관 표 번호와 달라졌다. | 기관의 표 순서를 먼저 번호로 부여한 뒤 좌표가 있는 항목만 그린다. | 표의 2번 기관은 1번에 좌표가 없어도 위치 개요에서 2번으로 표시된다. 최대 앞 18개 행 표시 기준은 유지한다. |

수정 범위: `jinsulmap/jinsulmap.html`의 `scanSiteCompetition`, `scanSiteSnapshot`, `scanSiteDiagram`, `scanSiteSheet`, `scanSiteCompetitionHTML`, `scanSiteRenderCompetition`. 경쟁병원 포함 기준·환자 데이터·공통 스타일·API/Worker를 변경하지 않았다.

## 범위와 제한

검토 범위 내 수정은 검증 완료. 이 검사는 저장·렌더링 경로를 다루며 실제 외부 API 성공률이나 주소의 실제 위치 정확성을 검증한 것이 아니다. 인쇄 CSS 미리보기이며 브라우저 실제 PDF 저장/페이지 분할 전체 검증으로 집계하지 않는다. 로드뷰는 기존 원문 링크 출력 방식이며 촬영 이미지 자동 복제는 추가하지 않았다. 최종 수정본의 디버깅 3회·기능 3회·배포·배포 후 3회 기록은 루트 릴리스 검사에서 별도로 실행한다.
