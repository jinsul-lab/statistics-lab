# 환자 기능 점검 · v3.8.4

## 확인한 문제와 수정

1. **주소 변환 진행과 집계 화면의 시점 불일치**
   - v3.8.3은 좌표를 찾는 즉시 마커를 표시하지만 환자·기록 합계와 열린 통계는 주소 처리 전체가 완료될 때 갱신했다. 반경이 적용된 경우 현재 지도와 합계가 수분간 달라질 수 있었다.
   - 시작 시 현재 필터 합계를 적용하고, 진행 중 합계·열린 통계를 최대 750ms에 한 번 갱신한다. 작업 완료·초기화·새 업로드 시 오래된 갱신을 취소한다. 통계 탭과 현재 필터를 유지한다.
2. **현재 분석 범위를 무시하는 위치 맞춤**
   - 이전 위치 맞춤은 모든 환자 마커를 사용했다. 유형 또는 반경으로 제외한 환자까지 화면 범위에 포함했다.
   - 현재 유형·반경에 맞는 좌표만 사용한다. 좌표가 없으면 안내만 표시하고 빈 지도 경계를 SDK에 전달하지 않는다. 마커 생성 여부로 좌표를 누락하지 않는다.
3. **초기화 뒤 이전 통계 화면 잔류**
   - 이전 초기화는 데이터와 캐시를 지워도 열린 통계를 닫지 않았다.
   - 초기화 시 통계를 닫고 예약된 진행 갱신도 취소하여 새 자료를 올리기 전 이전 분석이 표시되지 않게 했다.
4. **취소된 업로드의 늦은 시작**
   - 실행 예약된 이전 업로드가 새 업로드 이후 시작하면 처리 상태를 먼저 바꾼 뒤 취소 여부를 확인했다.
   - 시작 지점에서 업로드 식별값을 검사하여 새 자료를 건드리지 않게 했다.
