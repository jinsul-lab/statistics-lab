# JINSUL MAP v3.8.4 지도 기능 점검

2026-10-25, 대상: 단일 배포 HTML `jinsulmap/jinsulmap.html`.
합성 응답을 사용한 로컬 검증이며 실제 외부 API 정상 응답의 증거와 구분한다. 실제 환자 자료·계정·인증키는 사용하거나 기록하지 않았다.

## 확인한 오류와 수정

1. **우리 병원 검색의 무응답·이전 요청 처리**
   - 이전에는 장소 검색과 주소 검색 중 하나가 응답하지 않으면 결과창이 열리지 않았다. 병원 설정 해제 후 늦은 응답이 결과창을 다시 여는 경로도 있었다.
   - 각 소스에 8초 제한을 적용하고 성공·결과 없음·오류를 구분했다. 일부 소스 실패 시 확인된 결과를 표시하며 안내한다. 설정 해제 및 새 검색으로 이전 응답을 무효화한다.
   - `address`가 비어 있는 주소 응답, 좌표 누락·범위 오류를 처리한다. 결과 중복은 이름과 위도·경도를 함께 비교한다. 외부 이름·주소는 HTML로 삽입하지 않고 문자로 표시한다.
   - 결과를 Tab으로 선택하고 Enter·Space로 실행할 수 있다. 버튼 역할과 이름·주소를 포함한 접근성 이름을 제공하며, 키를 누르고 있을 때 중복 선택하지 않는다.
2. **현수막게시대의 비동기 레이어 복원**
   - 시설 스캔에서 넘긴 요청 유효성 검사에는 현수막 버튼 OFF가 반영되지 않아, 버튼을 끈 뒤 늦은 응답이 마커를 다시 만들 수 있었다. 지도 범위가 바뀐 뒤 이전 범위의 응답이 새 결과를 덮는 경로도 있었다.
   - 레이어 표시 상태와 최신 그리기 요청을 함께 검사한다. 중지·전체 초기화 시 대기 중 그리기, 지도 이동 감지 및 지연 타이머를 정리한다. 실패한 새 조회는 이전 상세 목록도 비운다.
3. **현수막 자료의 엑셀 출처 누락**
   - 화면에 표시한 공식 API/보관 CSV와 기준일이 시설목록 엑셀에는 기록되지 않았다.
   - 현수막 자료의 출처·자료 기준·조회 상태를 엑셀에 포함한다. API 실패로 보관자료를 쓴 경우 별도로 표시하며, 과거 레코드에 상태가 없으면 `미확인`으로 남긴다.

## 한계

- 이번 지도 하위 점검은 실제 카카오·서울 공식 API의 전국 결과 완전성이나 현장 운영 여부를 보증하지 않는다.
- 서울 밖 공식 쉼터 자동 연결 미지원 안내와 경비실·관리사무소의 보조 문의처 구분을 유지했다.
