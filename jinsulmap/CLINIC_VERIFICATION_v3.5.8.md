# JINSUL MAP v3.5.8 의원 업종 분석 검증

기록일: 2026-09-07. 기준 v3.5.7. 최종 앱은 단일 `JINSUL_MAP_v3.5.8.html`.

## 변경
- 상세 분석의 **의원 업종** 탭에 서울 공식상권·일반의원/치과의원/한의원 선택 추가.
- 최근 4분기 점포 수, 개업·폐업 비교, 요일·시간대·결제 연령대·성별 추정매출 등 6개 차트와 수치표.
- 탭을 열 때만 조회하고 진행률 표시. 매출 페이지는 2개씩 처리하며 기존 네트워크 재시도·취소를 사용한다. 완전한 분기 조회만 메모리 캐시한다.
- 상권·분기·업종을 엄격하게 일치시킨다. 중복 행, 페이지 누락, 조회 중 원본 건수 변경은 결과를 합산하지 않고 오류로 표시한다.
- 기존 환자 업로드·지도·필터·점수 계산식은 유지. 새 의원 매출은 탐색 점수에 반영하지 않는다.

## 공식 출처와 해석
- 서울시 분석서비스: https://golmok.seoul.go.kr/owner/owner.do
- 점포: https://data.seoul.go.kr/dataList/OA-15577/A/1/datasetView.do (`VwsmTrdarStorQq`).
- 추정매출: https://data.seoul.go.kr/dataList/OA-15572/A/1/datasetView.do (`VwsmTrdarSelngQq`).
- 코드: CS200006 일반의원, CS200007 치과의원, CS200008 한의원.
- 서울특별시·서울신용보증재단 출처를 화면에 표시. 공개 데이터로 새 차트를 구성했으며 사이트의 샘플 숫자·비공개 API를 사용하지 않았다.
- 선택된 공식상권 전체 통계이며 원형 반경 합산이나 특정 병원·진료과별 매출이 아니다. 보험 청구액·고유 환자 수로 해석하지 않는다.
- 분기와 원본 금액(원)을 보존하고 월평균·연매출로 환산하지 않는다. 연령·성별 합계가 전체 금액과 다를 수 있다.
- 서울 밖에는 기존 전국 심평원·SGIS·상가·관광공사 통계를 유지한다. 서울 의원 업종 자료를 전국 값으로 확대하지 않는다.
- 생존율·평균 영업기간은 미연결이며 임의 계산하지 않는다.
