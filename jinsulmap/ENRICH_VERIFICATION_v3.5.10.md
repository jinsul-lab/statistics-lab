# v3.5.10 병원 상세 및 입지자료 자동 반영

2026-09-07

## 변경
- 병원 클릭 상세를 심평원과 국립중앙의료원 병의원 목록 조회로 확장. 월~일·공휴일 시간표, 전화, 진료과, 전문의, 점심·휴진 안내, 주차·오시는 길 중 제공된 항목 표시.
- 동명 병원은 이름과 전화, 전화가 없으면 주소 또는 100m 이내 좌표로 대조. 일치 후보가 여러 개면 채택하지 않음.
- 빈 시간은 휴진으로 해석하지 않음. 공급자별 시작·종료를 혼합하지 않음. 소스 실패 시 다른 소스의 성공 자료 유지.
- 입지자료 첫 열기에서 가까운 경쟁의원 5곳 자동 수집. 추가 버튼으로 최대 20곳 수집. 수집한 시간·전화·진료과·오류 및 출처를 입지자료 표와 JSON/HTML에 보관.
- 건축물대장 주차·승강기를 빈 입력란에 자동 반영하고 건물 전체 수량임을 표시. 후보 의원이 정확히 식별되면 대표전화를 자동 반영. 기존 수기값 보존.
- 임대가격·전용면적·공실·배정 주차는 확인되지 않은 값을 생성하지 않음. 지역명 대표지점에는 건물 자동 입력하지 않음.
- 네이버 지도 검색 링크 추가. 네이버 페이지 내용을 자동 복제하는 기능은 아님.

## 검증
- 새 상세·자동 입력 모의 테스트 21개 통과.
- 최종 HTML 기존 API34·의원업종14·관광방문자10·UI13 = 71개 회귀 검증 통과. 합계92개.
- 브라우저 모의 UI: 건물85대·승강기2대 자동 입력, 출처 표시, 월09:00~18:00(심평원)·화09:00~18:30(국립중앙의료원) 보완 및 자료표 반영 확인. 실제 병원 시간 아님.
- 모든 인라인 스크립트 구문 검사 통과.

## 실제 API 및 남은 연결
- 국립중앙의료원 공식 안내: https://www.data.go.kr/data/15000736/openapi.do
- 전국 범위·무료·개발/운영 자동승인. 기존 앱 키로 서울본정형외과의원 / 경기도 목록 조회를 실제 실행했으나 HTTP403, 인증 코드30 수신.
- 공공데이터포털 로그인 세션이 만료되어 사용자 로그인 요청 중. 해당 서비스 활용승인 및 승인 키 일치 확인 후 재검증 필요. 진료시간 실제 수신 성공으로 보고하지 않음.
- 기존 심평원 원본에 시간이 없으면 승인 전에는 시간표가 미제공으로 남는다.
- 신규 버전 운영 스캔·OS 인쇄는 이 기록 작성 시 미검증. Workers 변경 없음.
