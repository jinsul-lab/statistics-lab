# JINSUL MAP v3.5.7 UI 검증

기록일: 2026-09-07. 기준: `JINSUL_MAP_v3.5.6.html`. 산출물: 단일 `JINSUL_MAP_v3.5.7.html`.

## 변경과 이유
- 이전 테마의 `-webkit-text-fill-color: transparent` 상속을 제거하여 제목 안의 배지도 읽히게 수정.
- 흰 바탕 위 노랑/연두 환자 필터 글자를 진한 색으로 변경. 원래 색상 점, 지도 마커, 필터명은 유지.
- 밝은 버튼 위 흰 글자, 옅은 회색 9~10px 보조 텍스트 개선. 새 주요 색상 조합은 대비 4.5:1 이상으로 검증.
- 두 통계 팝업 최대 폭 1,560px, 뷰포트 높이 96% 사용. 본문 14px, 제목 18px, 핵심 수치 24~25px. 좁은 폭에서는 카드와 차트를 한 열로 재배치.
- 인구 탭 최상단에 서울 실시간 현재 추정 범위, 기준 시각, 혼잡도, 비상주/성별 비율, 전체 예측 시점 표시.
- 실시간 최소/최대 범위 선·음영, 8개 연령대 막대, 성별 도넛, 상주/비상주 누적 막대. 현재·예측 및 구성 수치표 제공.
- 전국 방문자 분류별 시계열, 공식상권 시간대 선·요일/연령 막대 추가. 기존 상세 수치도 보존.
- SGIS 인구·가구·주택·밀도·사업체·종사자·연령 지표를 상세 통계에 통합.
- 환자 통계의 지역·실시간 인구 탭에서 입지 인구 상세 열기. 환자가 없고 스캔 결과만 있어도 통계 버튼으로 인구 상세 접근.
- 실시간 빈 필드는 null로 보존. 방문인구 미제공 날짜는 선을 잇지 않으며 0은 실제 0으로 유지.

## 범위와 제한
- 서울 지정지점 인구는 후보지 반경 합계가 아니며, 예측은 확정 실측이 아님. 관광공사 시군구 일별 방문자와 서울 분기상권을 합산하지 않음.
- 전국 모든 주소, 모든 브라우저/모바일 기기, 환자 실제 파일 업로드 전체 경로는 이번 UI 작업에서 재검증하지 않음. 기존 업로드·계산식·마커 색상 로직은 유지.
- 초기 v3.5.7 운영 수신 후 작은 글씨·축 배치·환자 필터 대비를 마무리 조정. 최종 코드의 로컬 검증은 통과했으며 세부 배포 확인은 아래 후속 기록에 남김.
- GitHub 앱으로 업로드. 기존 프록시는 변경하지 않음. 로컬/원격 이력이 다르므로 강제 push 금지.
