# 진설맵 분석·명칭 검토 — v3.7.1

2026-09-29 · **조건부 사용 가능 / 검토 범위 Partial**

수정 전 분석은 모두 정확하다고 볼 수 없었습니다. 아래의 재현 가능한 계산·표현 오류를 수정했습니다. 실제 환자 원본과 외부 API 전체를 대조한 인증이 아니라, 현행 HTML의 계산 경로와 가상 자료를 검증한 결과입니다. 공개 URL은 https://jinsul-lab.github.io/statistics-lab/jinsulmap/jinsulmap.html 입니다.

## 우선 발견 사항과 조치

1. **환자 기록을 실제 방문·재진 전환으로 오인.** 날짜나 방문ID를 읽지 않고 한 행을 한 기록으로 세었습니다. **수정:** 내원 기록 수, 신환 반복기록 비율로 표시하고 공식·분모·90일 분류·기간 한계를 화면에 명시. 완전히 동일한 행은 경고하며 임의로 삭제하지 않음. 실제 재방문율은 산출하지 않습니다.
2. **원평균과 다른 보정값.** 기존 평균은 내부 K=10 보정값이었습니다. **수정:** 기록 합계÷환자 수로 통일. 가상 지역 A 10기록/2명=5.00, B 4기록/2명=2.00 확인. 과도한 단골화·마케팅 효율 추천 제거.
3. **환자 식별·주소·반경 오류.** 일반 번호 열을 환자ID로 잘못 선택, N/0/아니오 신환 판정, 동명이 지역 합쳐짐, 수동 반경 무시, 주소 조회 조기 완료가 있었습니다. **수정:** 차트번호 우선, 부정 표기 처리, 시도·시군구 포함, 공통 반경, 완료 카운터·취소 토큰. 음수/월령 나이도 수정.
4. **자료 없음과 0의 혼동.** 거리표 빈 자료1명, 빈 누적반경3km+, 비율 분모0, 0배수 누락, 외부 조회 실패0건이 있었습니다. **수정:** 실제 0과 null 구분. 차트 라이브러리 장애 시 음수·누락을 보존하는 수치표로 대체.
5. **입지 점수의 근거 부족.** 남아 있던 인구/상가/시설 환산에도 검증되지 않은 임계값·가중치가 있었습니다. **수정:** 종합 점수와 점수 차트를 제거하고 원단위 자료·범위·시점으로 표시.

## 남은 확인 사항

- **환자 원본 대조:** 실제 고유 방문일/방문ID와 진료일 범위가 있어야 실제 방문 횟수·재방문율을 계산할 수 있습니다. 현재는 업로드 행 기준입니다. 동일 환자의 관찰기간 차이는 보정하지 않습니다.
- **원본 신환 표기:** 기존 비어 있지 않은 표기 호환성을 유지하되 명시적 N/0/아니오를 제외했습니다. 사용 병원 파일의 기타 특수 표기까지 대조하지 않았습니다.
- **건물 특정:** 필지 내 첫 대표 대장을 자동 선택하는 경로가 남아 있습니다. 실제 입주 동·호실 일치 확인이 필요하며 자동 수치를 확정 임대정보로 사용하면 안 됩니다.
- **부동산 거래:** 조회한도 도달/월별 실패는 집계에서 구분하지만 취소·정정 거래의 원본 정책과 일치 여부를 검증하지 않았습니다.
- **외부 자료:** R-ONE·SGIS·심평원·서울시·관광공사 전 지역 실시간 연결, 원기관 최신성, 실제 병원 영업 여부를 이번 검토로 보증하지 않습니다.
- **출력:** 기존 PDF/로드뷰 출력 기능은 이번 범위에서 재검증하지 않았습니다.
