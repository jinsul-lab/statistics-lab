## 검증

- work/test_personas_v381.cjs: 합성 UTF-8/CP949 바이트가 실제 processFile 해석 경로에서 동일 한글 문자열을 전달하는지 확인. XLSX 호출은 모의 객체이며 실제 공급자 Excel/CSV 전수 검증 아님.
- 제외행 합성 참조: 비어 있지 않은 원본4행, 분석2행, 번호 없음1행, 반복 헤더1행. 고유 환자1명/기록2건/동일 행 중복1건.
- 후보지 비교 모의 상태: 실패0건은 조회 불가, 정상0건은 0곳, 부분2건은 일부 미확인. 미저장 옛 자료는 당시 누락된 오류 상태를 복원할 수 없으므로 재스캔 필요.
- patient_audit_v380, test_io_coverage_v380, test_banner_layout_v380 통과. 인라인 JavaScript 구문 검사 포함.
- test_patient_current: 실제 Chart.js와 합성 자료로 전체 환자 탭·산점도·필터·빈값·태블릿 렌더 검사 통과, 브라우저 오류 없음.
- 의원 기준159개·경로당/쉼터204개 모의 검사 통과. 이번 변경에서 해당 공공 API를 전국 재조회하지 않음.
- 사진 안내·태블릿 CSS·초기화 코드 경로 확인. 실제 PDF 파일을 새로 생성해 영상 포함 여부를 검증한 것은 아님. 기존 링크 출력 방식 유지.

1. 입지자료 편집 미저장 표시와 후보지 전환 보호. 자동 수집/수동 편집/저장 시점을 함께 다뤄야 함.
2. 손상된 브라우저 저장자료 복구·백업 안내. 원본을 덮어쓰지 않는 방식으로 구현 필요.
3. 경쟁병원 판정에서 전문의0·미확인·기관분류 미확인 상세 수치 안내 확대.
