# JINSUL MAP 3.7.6 · 경쟁 후보와 조회 출처

## 확인된 문제

기존 ‘경쟁 의원’은 카카오 장소 검색 결과이고 ‘심평원 의원’은 선택 진료과를 신고한 의원급 결과였다. 서로 배타적인 경쟁/비경쟁 분류처럼 보이는 명칭이 잘못됐다. 심평원 정형외과도 경쟁 후보이며, 입지자료 경쟁의원 비교는 이미 심평원 자료를 사용한다.

## 수정

- 상세창·범례: ‘경쟁 후보 · 카카오 검색’, ‘경쟁 후보 · 심평원 신고자료’로 출처를 명시.
- 필터: ‘카카오 검색’, ‘심평원 신고자료’. 두 자료 모두 선택 진료과 경쟁 후보라는 안내 추가.
- 상세창: 카카오는 진료과 키워드 검색, 심평원은 신고 진료과 기준이며 전문의 여부와 다름을 설명. 비동기 상세 수신 후에도 설명 유지.
- 같은 기관이 양쪽에 포함될 수 있으므로 두 개수를 합산하지 않음을 안내. 기존 좌표·수집·집계·색상 유지.
- 동일 위치에 마커가 겹치면 심평원 마커가 위에 보일 수 있다. 표시 출처는 경쟁 여부를 의미하지 않는다. 이름·근접 좌표만으로 다른 기관을 합치지 않았다.

## 검증

- `work/test_map_ui_current.cjs`: 정형외과의 경쟁 후보·출처 설명, 상세 수신 후 유지, 약국에는 안내 미표시, 이전 응답 격리, 닫기, 1280/1024/768 폭 배치·스크롤·도구 분리 통과. 합성 자료로 실제 HTML 함수를 실행.
- `work/test_competition_current.cjs`: 기존 반경 경계·누락 거리·집계 및 인라인 JavaScript 구문 통과.
- `work/test_markers_current.cjs`: 6개 아이콘 SVG·크기·캐시·색상 및 최신 출처 명칭 렌더 통과.
- 태블릿 상세창 이미지 확인. 이번 변경에서 외부 병원 API 전수 조회, 동일기관 통합, 실제 환자 원본은 재검증하지 않았다.

## 추가로 필요한 전국 쉼터 API

- [행정안전부_무더위쉼터](https://www.safetydata.go.kr/disaster-data/view?dataSn=1338): 재난안전데이터공유플랫폼 회원가입·로그인 후 이용신청.
- 전국 전체 조회용 REST API이며 별도 서비스 인증이 필요하다. 기존 공공데이터포털 일반 키만으로 승인됐다고 볼 수 없다.
- 서울 공식 쉼터는 기존 승인 API로 연결돼 있다. 전국 연결은 해당 서비스 승인·키 등록 후 진행하며, 이번 버전에 전국 연결 완료로 표시하지 않는다.
