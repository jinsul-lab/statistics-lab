## 이번에 수정한 오류
1. 경쟁의원 제외 변경 등으로 스냅샷을 다시 만들 때 병원 상세·대장 근거가 사라지는 경로 수정. 동일 층의 서로 다른 용도 구획은 각각 유지하고 완전히 동일한 근거만 중복 제거.
2. 건축물대장 주차·승강기 원본 필드가 없는데0대로 계산되던 경로 수정. 모든 구성 필드가 있을 때만 합산. 실제0과 미제공을 지도 패널·상세·후보 비교·보고서에서 구분.
3. 대장 페이지 중복 행·총건수 초과·총건수 변경을 감지해 면적 합산 중단. 중복 응답으로 전유면적이 부풀려지지 않게 처리.
4. 자동 호실에서 호실명을 수정하면 이전 호실의 자동 면적과 선택 근거 제거. 직접 입력한 면적은 보존. 수정한 필드의 자동 입력 배지도 즉시 제거.

## 다음 개발 우선순위
1. **실제 매물 원문 연결**: 매물번호·층/호실·등록일·전용면적·임대조건을 확보하고 건축물대장과 대조. 현재 전국 민간 매물 자동 연동은 미구현. 임대조건 빈칸을 시세로 채우지 않음.
2. **경쟁의원 검색 정밀도**: 카카오 키워드 결과에 의료기관 이외 업종이 섞이는지 분류표본 점검 후 심평원 기관과 교차 표시. 기존 탐색점수 계산은 이번에 변경하지 않음.
3. **갱신 관리**: 동일 후보지 재조회 시 오래된 자동 자료의 갱신 정책·변경 내역·수기값 충돌 표시를 개선할 여지. 현재 조회일 표시는 유지.
4. **현장 검증 항목**: 실제 공실·환자 무료주차·승강기 접근·간판권·부분임대 도면은 원문/임대인 확인과 구분. 공개 API 값만으로 확인 완료 처리하지 않음.
5. **표본 확대**: 집합건물 복수호실·분할임대·넓은 반경·저장본 복원에 대한 실제 표본과 인쇄 검증 확대. 이번 수정에서 OS 인쇄 대화상자를 재검증하지 않음.
