# JINSUL MAP 3.7.4 · 지도 UI 및 시설 검색 검증

검증일: 2026-09-29. 기준: `jinsulmap/jinsulmap.html`. 고정 URL 유지.

## 수정

- 병원 상세를 지도 안의 크기 제한 패널로 전환. 지도 도구와 분리, 내부 스크롤, 고정 제목·닫기, Escape 지원. 높은 z-index 마커가 상세 내용 위에 나타나던 문제 제거.
- 좁은 화면의 3열 자료표를 항목·값·출처 순서로 배치. 모든 요일의 진료시간이 미제공이면 요약하고 원래 요일별 결과를 펼쳐볼 수 있게 유지. 미제공을 휴진으로 해석하지 않음.
- 상권 마커: 후보지 주황, 경쟁 의원 붉은색, 심평원 청록, 지하철 파랑, 주차 진회색, 약국 보라. 범례·필터에 동일 그림 아이콘 적용. 환자 분류 색은 유지.
- 기본 시설 검색: 경로당·노인정·마을회관·무더위쉼터. 관리사무소·관리실·경비실은 기본 해제된 보조 옵션.
- 경비실을 경로당으로 저장하지 않음. 보조 결과는 회색 물음표와 ‘보조 문의처’, 시설·방문 경로 Excel에도 ‘노인시설 여부 미확인’ 표시.
- 직접 시설은 장소 ID로 중복 제거. 아파트 단지명만으로 실제 경로당/쉼터 여러 곳을 합치던 처리 제거. 보조 문의처 대체는 단지명과 도로명주소가 모두 일치할 때만 적용.
- 오류/시간 초과와 정상 0건, 일부 페이지 수신, 한도 도달 가능 구분. 초기화·재검색 시 이전 경로 제거 및 늦은 결과 무시.

## 카카오 공개 정책 확인

경비실 검색은 API 정책상 의무가 아니라 기존 앱의 보완 로직이었다. 경로당 전용 카테고리 그룹은 제공하지 않지만 키워드 검색은 가능하다. 공개 API와 카카오맵 앱의 검색 결과는 다를 수 있다. 키워드 검색은 최대 45개 문서 범위이므로 전체 시설 전수 목록으로 설명하지 않는다.

- [공식 Local API 문서](https://developers.kakao.com/docs/ko/local/dev-guide#search-by-keyword)
- [경로당 카테고리 그룹에 관한 카카오 답변](https://devtalk.kakao.com/t/api/141616)
- [최대 검색 결과에 관한 카카오 답변](https://devtalk.kakao.com/t/topic/143464)
- [카카오맵과 API 검색 결과 차이](https://devtalk.kakao.com/t/topic/137799)

## 실제 API 검증

실제 배포 도메인의 Kakao JavaScript SDK와 새 검색 helper를 사용했다. 주소는 경기도 시흥시 정왕대로 74, 범위는 주소 중심 위도 ±0.009 / 경도 ±0.0113의 사각형(대략 2km × 2km)이다. 앱의 원형 반경 스캔과 다른 범위이므로 개수를 직접 대조하지 않는다.

|키워드|수신 건수|결과|
|---|---:|---|
|경로당|12|OK|
|노인정|12|OK|
|무더위쉼터|0|ZERO_RESULT|
|경비실|10|OK|

키워드 간 중복이 있으므로 합산 불가. 무더위쉼터 0건은 해당 API·검색 범위에서 미검색이며 실제 시설 부재의 증거가 아니다. 별도 지자체 쉼터/노인복지시설 데이터 연계는 이번 변경에 포함하지 않았다.

## 검증 결과

- `test_senior_current.cjs`: 실제 HTML 함수·검색 handler를 대상으로 74개 모의 검사 통과. 직접/보조 분류, 페이지·실패·0건, 내보내기, 취소·늦은 응답, 이전 경로 제거.
- `test_map_ui_current.cjs`: 1280×900 / 1024×768 / 768×1024 패널 위치, 도구 비겹침, 스크롤, 마커 쌓임, Escape, 다른 시설 선택 후 늦은 응답 무시.
- `test_markers_current.cjs`: 6종 SVG 수신·디코딩·캐시·크기 통과, 시각 확인.
- 기존 환자 통계·분석 계산·입지 데이터 결측·경쟁 분석 회귀 스크립트 통과.
- 실제 전국 모든 시설, 모바일 Safari, 전체 외부 API 및 PDF 출력은 이번에 전수 검증하지 않았다.
