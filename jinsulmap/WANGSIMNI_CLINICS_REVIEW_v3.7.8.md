# 왕십리로 320 누락 신고 확인 · 3.7.8

검증일: 2026-09-30 (한국시간)

## 실제 공개 API 확인

건강보험심사평가원 병원정보서비스 `getHospBasisList`, 의료기관별 상세정보서비스 `getSpcSbjtSdrInfo2.8`, `getEqpInfo2.8`, `getDgsbjtInfo2.8`를 실제 호출했다. 각 응답의 성공 코드 `00`, 전체 건수와 수신 건수 일치를 확인했다. 브라우저 실행 검증과 구분되는 서버 전송 검증이다.

중심은 왕십리로 320에 있는 **왕십리본정형외과의원**의 심평원 좌표(위도 37.5623492, 경도 127.0343485)를 사용했다. 아래 거리는 이 좌표 기준 직선거리다. 앱 주소 검색 좌표와 소폭 다를 수 있다.

| 서울마취통증의학과의원 | 서울특별시 성동구 왕십리로 315, 6층 (행당동, 한동타워) | 의원 31 | 마취통증의학과 1명 | 허가 1, 일반 1 | 67.5m | 05·06·09·21에서 반환 |

`허가 1`과 `일반 1`은 중복되는 병상 지표이므로 합산하지 않는다. 물리치료실 베드는 서울마취통증의학과 7, 자세본 12, 왕십리본 14이며 입원 병상으로 계산하지 않는다. 전문의 API는 신고 현황이고 실제 상주·당일 진료를 증명하지 않는다.

## 누락 단계 판정

- **서울마취통증의학과의원:** 목록 수집·좌표·반경 문제가 아니다. v3.7.7에서 입원 병상 1개를 근거로 제외하던 분류 규칙 때문에 경쟁 지도에서 빠진다. 사용자가 병상 보유 의원도 포함하도록 확정했으므로 v3.7.8에서는 의원급·전문의 신고로 경쟁에 포함하는 것이 맞다.
- **자세본재활의학과의원:** 실제 API 수집에 문제가 재현되지 않았다. 재활의학과를 선택한 반경 1km에서는 목록이 반환되고 v3.7.7의 전문의·병상 조건도 통과한다. 반경 500m에서는 범위 밖이며 재활의학과 미선택 시에도 조회 대상이 아니다. 과거 누락 화면의 반경과 필터는 확정하지 못했고, 수정판 실제 브라우저 결과는 아래에 기록했다.

## 수정 후 실제 브라우저 확인

현재 단일 HTML을 로컬 HTTP 서버에서 열어 실제 API로 **왕십리로 320 주소 검색 → 반경 1km → 4개 진료과 모두 선택 → 상권 스캔**을 실행했다.

- 경쟁병원 12곳, 심평원 신고의원 14곳, 분류 확인 필요 0곳, 제외 0곳.
- 서울마취통증의학과의원 **67m**, 자세본재활의학과의원 **971m**가 모두 경쟁 목록에 표시됨을 확인했다.
- 브라우저의 주소 검색 중심과 위 심평원 기관 좌표의 차이로 자세본의 거리가 약 7m 다르게 나타났다. 두 계산 모두 반경 1km 안이다.
- 자세본의 과거 누락 원인은 현재 반경 1km 화면에서 재현되지 않았다. 따라서 과거 오류가 특정 원인 때문이었다고 단정하지 않는다. 반경 500m의 범위 밖이라는 사실과 수정판 1km의 실제 표시를 구분해서 기록한다.
- 입지자료 표에서도 두 기관을 포함한 경쟁 12곳, 각 전문의 수와 병상 참고 정보가 표시됐다. 서울마취통증의학과의원은 입원 병상 ‘보유 확인’인 상태로 경쟁 목록에 유지됐다. 기존 저장자료에 시험 결과를 저장하지 않았다.

## 현재 기준과 회귀 검사

경쟁병원은 의원 종별 `31`이며 선택한 정형외과·신경외과·마취통증의학과·재활의학과 중 전문의 신고가 1명 이상 확인된 기관이다. 병상 유무·병상 조회 실패는 경쟁 분류에 영향을 주지 않는다. 선택 진료과목 신고가 있으나 전문의 0명 또는 미확인이면 심평원 신고의원에 남기며 두 상태를 구별한다. 병원·종합병원·상급종합병원 등 의원 외 종별은 제외한다.

- `test_clinic_criteria_v378.cjs`: 모의 159개 통과. 분류·병상 독립성·전문의 0/미확인·페이지 완전성·오류 재시도·캐시·취소·동시성.
- `test_clinic_api_fixtures_v378.cjs`: 이전 실제 수집 API 10기관 기록 재생 통과(경쟁 4·신고 6). 병상 독립성 30개, 전문의 조회 실패 시 신고 유지 10개 추가 통과. 실행 중 새 API 호출은 없음.
- `test_clinic_integration_v378.cjs`: 모의 69개 통과. 신고의원 마커/목록·입지자료·저장/가져오기·출력, 전문의 미확인 값과 일부 미확인 상태 보존.
- 기존 `test_patient_competition_v377.cjs`: 현재 HTML의 환자 시설 검사 32개 및 시설 검색 회귀 204개 통과.
- `test_competition_current.cjs`, `test_map_ui_current.cjs`, `test_patient_current.cjs` 통과. 실제 Chart.js와 합성 환자 데이터를 사용한 UI/통계 회귀이며 실제 환자 원본 검증과 구분한다.
- `git diff --check` 및 인라인 JavaScript 구문 검사 통과.

v3.7.7의 엄격한 병상 제외 기준을 검사하는 구버전 테스트는 당시 기록으로 보존한다. 현재 분류 검증은 v378 테스트를 사용한다. 모든 지역·전국 의료기관·실제 PDF 프린터 출력은 전수 검증하지 않았다.
