# JINSUL MAP v3.5.9 입지자료·임장 검증

2026-09-07. 기준 v3.5.8. 단일 앱 `JINSUL_MAP_v3.5.9.html`.

## 사용 경로와 변경
- 상권 스캔 → 입지 상세분석 → **입지자료·임장**.
- 정형외과·통증·재활 중심 12개 현장 체크: 주차, 이동 접근성, 승강기, 간판, 치료실 동선, 전력·하중·방음, 영상장비, 약국·교통, 업종 제한, 개설 가능 여부, 임대조건, 시간대 현장 관찰.
- 건축물·주거/종사자·실시간/방문인구·R-ONE·약국/주차/역 접근 정보를 기존 스캔에서 연결. 자료별 공간 범위·시점·출처 표시. 임대 호실 면적과 건물 연면적을 혼동하지 않음.
- 보증금·월세·관리비·권리금·전용평·입주일·사진·임장 메모 직접 입력. 월세+관리비, 평당 월세, 평→㎡ 계산. 부가세 임의 가산 없음. 빈 값과 실제0 구분.
- 심평원 경쟁의원 거리 구간 차트, 거리·신고 의사·개설일·진료과 비교. 동일 이름+50m 이내 후보 의원은 이 비교에서만 제외 가능. 기존 지도·점수의 집계는 변경하지 않음.
- 가까운20곳 상세 버튼에서 기존 심평원 상세 API로 진료시간·주차·진료과 조회. 표는 가까운60곳, 위치 개요는18곳까지 표시하고 제한 명시.
- 의원 업종 탭의 조회 완료 자료는 상권·분기·업종 그대로 입지자료에 포함. 금액÷동일 업종 점포 수는 단순 비교값으로 표시하며 개별 경쟁병원의 매출이나 손익 추정에 사용하지 않음.
- 구·시 등 지역명 검색은 대표지점 주변 참고로 표시하고 건축물대장 후보 필지를 비움. ‘지역 내 의료기관 주변 찾기’는 해당 지역의 정형외과 검색 결과 최대15곳을 보여주고 주소를 다시 스캔하는 시작점을 제공. 전체 의료기관·지역 전체 분석·추천 매물로 표시하지 않음.
- 브라우저 저장 최대12개, 수동 저장/삭제, JSON 백업/복원, 독립 HTML 저장, A4 인쇄/PDF. 기존12개를 조용히 삭제하지 않고 한도 초과 안내.
- 사진은 JPG/PNG/WebP를 로컬에서 축소해 보관. 임대 메모·사진·연락처는 외부 서버에 업로드하지 않음. 내보낸 보고서에는 API 키·SDK·환자 자료를 포함하지 않음.

## 실제 화면과 PDF
- Pages v3.5.9의 ‘경기도 용인시’ / 1km / 정형외과·마취통증·재활 스캔 완료. 대표 좌표37.2410299792267,127.177482330871. 주변 반경상가420곳, 검색 경쟁/심평원0곳. 이는 용인시 전체 의원수가 아님.
- SGIS는 해당 조회에서 코드-1 오류. 정상 연결로 보고하지 않으며 입지자료에 미연결 표시. 넓은 지역 검색의 대표지점 주변 결과에는 명확한 지역 범위 안내를 표시함.
- 서울 외 실시간·의원 매출을0으로 만들지 않음. R-ONE은 조사권역 참고값으로 유지.
- 사용자 ‘입지 자료.png’를 바탕으로 `outputs/입지자료_부천_신흥로197_샘플.html`, `output/pdf/입지자료_부천_신흥로197_샘플.pdf` 작성. 현장 이미지와 원본을 유지하고 임대조건·인구를 제공 샘플/기준일 미상/미검증으로 표시. 현재 매물 조회로 주장하지 않음.
- Edge headless에서 동일 독립 HTML을 A4 PDF로 렌더링하고 Poppler로3페이지를 이미지화해 검수. 사진·위치·표·체크리스트·첨부원본의 한글 및 잘림 확인.
- 앱 인쇄는 iframe에 독립 문서를 만들고 브라우저 인쇄를 호출. Codex 내장 브라우저의 OS 인쇄 대화상자·사용자 실제 프린터는 미검증. 미지원 시 HTML 저장 후 Edge/Chrome에서 인쇄하도록 안내.
- 파일 선택을 통한 실제 사진 업로드/JSON 가져오기 전체 UI 경로는 미검증. 로컬 변환·스키마·사진 형식 처리는 코드 및 모의 테스트로 확인.

## 범위와 배포
- 기존 업로드·필터·마커·로드뷰·점수 계산식 유지. 주소 검색은 기존 해석을 보존한 래퍼에서 넓은 지역명 여부를 추가한다.
- 이번 버전은 프록시를 수정하지 않음. 전국 유동인구의 추가 계약이나 개별 병원 매출을 새로 확보한 것이 아님.
- 앱은 GitHub 커넥터로 배포. 로컬/원격 커밋 ID가 다르므로 강제 push 금지.
- 샘플 HTML/PDF는 사용자의 로컬 산출물로 제공하며 앱 HTML과 구분한다.

## 운영 후속 확인
- ‘경기도 용인시’ → 입지자료·임장 → 지역 내 의료기관 주변 찾기에서 실제 카카오 검색15곳 수신. 서울본정형외과의원의 ‘경기 용인시 처인구 백옥대로1142’ 주소를 선택하면 새 상세 스캔으로 전환됨을 확인.
- 저장/불러온 스냅샷은 원본 API가 없으므로 경쟁 제외 옵션을 비활성화. 해당 주소를 다시 스캔하면 변경 가능.
- 임시 PDF 렌더링 폴더 일괄 삭제는 환경의 자동 승인 정책에 의해 차단되어 로컬 tmp/pdfs에 남김. 앱·샘플 산출물과 별개.
