# JINSUL MAP v3.8.0 — 검증·디자인 개선

판정: **검토 범위 내 사용 가능, 자료 범위 주의(Share with caveats)**. 검증 범위는 **부분(Partial)**이며 모든 실제 환자 파일·지역·기기에서 무결함을 보증하지 않는다. 실제 개인정보 대신 합성 환자자료를 사용했다.

## 이번 수정

1. 환자번호 없는 파일에서 전화번호 등을 환자키로 오인해 환자를 합치던 경로 차단. 숫자 0 ID 보존, 미상 신환 표기 처리, 존재하지 않는 생일 배제, 첫 주소가 비어 있으면 후속 유효 주소 사용. 파일 읽기 실패 안내와 이전 파일 읽기 결과의 역전 방지. 환자 팝업의 ID·이름은 HTML로 실행되지 않도록 이스케이프.
2. 연령별 비율의 분모를 '연령 확인 환자'로 명시. 미상 포함 전체 인원과 확인 소계를 분리하고 빈 결과의 100% 제거. 연령 차트 인원 축 정수 표시. 거리 비교의 분모는 좌표 확인 환자임을 설명.
3. 현수막 상시 이름 라벨 제거. 가까운 게시대는 52px 기준 묶음, 클릭하면 상세 패널에서 전체 이름·주소·관리기관·전화·규격·기준일 확인. 같은 좌표도 개별 선택 가능하며 전체 목록으로 복귀 가능. 원래 게시대 데이터·좌표·색상·엑셀 행 유지.
4. 심평원 좌표 결측/범위 오류를 제외 건수와 일부 미확인 상태로 전달. 입원 병상 export는 항목 최대 참고값으로 명시. 일부 과 인원 결측 시 확인된 전문의는 최소 인원으로 표시. 의원급·입원 유무 무관 경쟁 기준 유지.
5. Paperlogy 유지. 사이드바 카드/버튼/입력/정보 상태 공통 여백·대비 정리. 시설 버튼 2×2 배치, 키보드 업로드/시설 선택, 통계창 44px 닫기 버튼과 Escape, 태블릿 탭 줄바꿈 적용. 긴 설명은 펼쳐 보는 방식, 핵심 집계 한계는 항상 표시.
6. 잘못된 RIGHTBOTTOM 위치 상수 및 도구 겹침 경로를 제거하고 별도 확대/축소 버튼 제공. 실제 지도에서 1km→2km→1km 변화 확인. 근거: https://apis.map.kakao.com/web/documentation/#ControlPosition

## 검증 증거

- 독립 합성 참조: 4명/7기록, 신환 반복기록1÷2=50%, 연령 확인3명 중20대2명=66.7%, 연령 미상1명, 최종 누적100%. VM 계산과 실제 CSV 업로드 화면 일치. 동일 행2건은 삭제하지 않고 중복 경고 표시.
- 실제 Chart.js 합성 브라우저: 유형·동·연령·기록·지역·반복기록·거리·구성 탭, 산점도4점, 필터/빈값/미상/0분모/CDN실패 안내 검사 통과. 실제 환자 원자료 정확성 검증 아님.
- 시설 모의검사: 경로당204, 환자경쟁32, 의원분류159, 통합69, 공식쉼터12, 쉼터 도우미39 통과. 모의검사 수는 자료 정확도나 전국 포괄률이 아님.
- 실제 브라우저 서울 기본 범위: 시설1328건(서울 공식1266건 포함), 검색 한도·중복 가능 안내 확인. 시흥 정왕대로210 검색 후 현 화면범위55건, 서울 밖 공식자료 미지원·검색한도 안내 확인. 지도 범위가 달라 수치 간 비교 금지.
- 현수막 API8331건 유지. 묶음 모의200개 보존/중복 좌표 선택, 실제 지도 겹침 제거 및0건 범위의 정상 안내 확인.
- 실제 768×1024 태블릿에서 통계 탭·차트·표·사이드바·줌 조작 점검. 데스크톱과 태블릿 상세 패널 회귀 검사 통과.

## 5개 가상 페르소나 검토

실제 인터뷰가 아니라 사용 목적에 따른 가상 검토다.

| 관점 | 핵심 의견 | 반영·후속 |
|---|---|---|
| 개원 검토 의사 | 경쟁 기준과 환자 기록 비율을 실제 내원율로 오해하면 안 됨 | 의원 기준 유지, 최소 전문의·분모·기록수 설명 강화 |
| 현장 조사자 | 마커·이름이 겹치면 방문할 장소 선택이 어려움 | 게시대 묶음·상세 목록·관리정보 제공, 예약 가능 여부는 관리기관 확인 |
| 데이터 분석가 | 미상/0·환자ID·반복 행·분모가 우선 | 독립 참조 계산, 오집계 원인 수정, 원자료 분류정책 유지 |
| 태블릿 사용자 | 좁은 화면에서 버튼 충돌과 작은 터치영역이 불편 | 2×2 시설,44px 버튼, 줌 분리, 탭 줄바꿈·대비 개선 |
| 운영 관리자 | 장애가 0건으로 보이거나 오래된 자료가 최신처럼 보이면 안 됨 | 좌표 미확인 경고, API/CSV 출처·기준일 보존, 검증기록 저장 |

## 남은 개선 우선순위

- 실제 사용 EMR의 여러 XLSX/CP949 CSV 표본으로 열 매핑·인코딩 검증 확대. 주민번호/보험번호 등으로 환자키를 추정하지 않음. 이번에는 합성 UTF-8 CSV만 실제 UI 업로드.
- 서울 밖 공식 무더위쉼터 데이터는 별도 연결이 필요하며, 현재 카카오 검색 한도와 지도 웹 대조를 안내한다. 이번 작업에서 전국 완전성을 확보했다고 주장하지 않음.
- 환자 실제 방문일을 이용한 코호트 재방문율은 명확한 방문일 정의·중복 정책이 마련된 후 별도 기능으로 구현. 기존 기록수 기반 분석을 임의로 변경하지 않음.
- 반복 지오코딩·API 비용과 오래된 저장자료의 재조회 정책을 후속 성능 점검 대상으로 유지. 이번에 확인하지 않은 기능까지 무결함으로 판정하지 않음.
