# JINSUL MAP v3.8.4 기능 개선·검증

검토일: 2026-10-25 (한국시간). 고정 배포 파일: `jinsulmap/jinsulmap.html`.

## 수정 내용

| 영역 | 확인한 문제 | 반영한 동작 |
|---|---|---|
| 환자 주소·통계 | 주소 처리 중 지도 마커와 반경 집계 갱신 시점이 달랐다. | 현재 유형·반경의 인원·기록과 열린 통계를 최대 750ms에 한 번 갱신한다. 활성 탭을 유지한다. |
| 환자 위치 맞춤 | 숨긴 유형·반경 밖 좌표까지 지도 범위에 들어갔다. | 현재 필터에 포함된 좌표만 맞춘다. 좌표가 없으면 빈 지도 경계를 전달하지 않는다. |
| 환자 초기화 | 초기화 후 열린 과거 통계나 예약된 갱신이 남았다. | 통계를 닫고 지연 갱신을 취소한다. 이전 업로드의 늦은 시작도 무효화한다. |
| 필터·탭 | 개별 필터를 꺼도 전체 선택 표시가 남았다. 프로그램으로 탭을 열면 선택 강조가 달라질 수 있었다. | 전체·일부·해제 상태를 실제 필터와 동기화한다. 통계 탭은 대상 ID로 선택 상태를 결정한다. |
| 화면 조작 | 작은 필터, 키보드로 도달하지 못하는 검색 결과, 팝업 밖으로 빠지는 초점. | 44px 필터 조작 영역, 일부 선택 표시, 초점 테두리, 방향키 탭 전환, 검색 결과 Enter/Space 선택, 팝업 내부 초점 이동과 Escape·닫기 후 초점 복귀. |
| 입지자료 | 시설 일부 조회 상태가 저장 후 사라졌다. | 일부 응답·조회 실패·실제 0건을 JSON 저장과 출력에 보존한다. |
| 거리 통계 | 거리 미확인을 0m로 표시하고 첫 거리 구간에 넣었다. | 미확인 표기 및 구간 제외 인원 안내. 실제 0m는 포함한다. 모든 거리가 미확인이면 차트도 자료 없음으로 둔다. |
| 입지 개요 | 좌표 없는 의원 때문에 그림 번호가 표 번호와 달랐다. | 원래 표 번호를 유지한다. |
| 병원 기준점 검색 | 한 검색 소스가 무응답이면 전체 결과가 열리지 않았다. 해제 후 늦은 결과가 돌아왔다. | 소스별 8초 제한, 부분 결과 안내, 해제/새 검색 뒤 이전 응답 무효화, 좌표 검증 및 문자 안전 표시. |
| 현수막게시대 | 해제·초기화·범위 이동 후 늦은 응답이 지도를 다시 덮었다. | 표시 상태와 최신 요청을 확인하고 대기 타이머·이동 감지를 정리한다. |
| 시설 엑셀 | 현수막 출처·기준일이 내보내기에 빠졌다. | 출처·자료 기준·공식 API/보관자료 사용 상태를 함께 저장한다. |

기존 환자 분류·인원/기록 정의, 경쟁의원 포함 기준, 마커 색상, Paperlogy, 고정 주소는 유지한다. Worker·인증키는 변경하지 않았다.

## 반복 검증

- 디버깅 3회: 신규 환자 14·입지 8·지도 45개 검사, 기존 주소 18·지리 49·업로드 28·의원 통합 69·경로당/쉼터 204개 검사와 현수막 배치·전체 인라인 구문 검사. 같은 최종 HTML 해시로 실행.
- 기능 검사 3회: 필터/팝업/키보드, 실제 Chart.js 진행 갱신, 통계 전체 탭·산점도·빈값·소표본, 계산/분모/거리 경계, 업로드 주소 UI, 입지 출력의 1280·768·375px 및 A4 인쇄 CSS.
- 원본 실행 시각·해시·출력: `work/release-v384-debug.json`, `work/release-v384-functional.json`.
- 중간 실패: 이전 주소 UI 테스트가 새 집계 함수의 의존 함수를 로드하지 않아 대기 시간 초과. 실제 함수를 주소 처리 전에 로드하도록 테스트를 수정했고 기존 검증 조건은 유지했다. 최종 코드 변경 이후 디버깅부터 다시 3회 수행했다.

## 실제 연결 확인

로컬 수정본을 인앱 브라우저에서 열어 공개 주소만 사용했다.

- 공개 시청 주소 4건 업로드: 좌표·행정동 4건 확인, 오류 0건.
- 서울 중구 세종대로 110 검색: 주소/장소 결과 및 기준점 선택 성공.
- 경로당·쉼터 검색: 서울 공식자료와 카카오 결과 표시, 키워드 결과 제한 가능성 안내 유지. 해당 지도 범위에서 나온 자료이며 전국 완전성 검사가 아니다.
- 현수막 공식 API: 전체 9,038건, 당시 지도 범위 220건·26개 묶음. 자료 기준일 2024-08-01~2026-09-19. 제공기관 범위 한계 안내 유지.
- 실제 시설 엑셀 220행: 출처·자료 기준·조회 상태 열과 값 보존 확인. 표시 해제 후 상세 패널 숨김 확인.

## 판정과 한계

검토·수정 범위는 검증 완료이며 자료의 제공 범위에 관한 주의사항과 함께 사용할 수 있다. 모든 기능·모든 지역·모든 API가 무결함이라는 판정은 아니다.

- 이번 작업에서는 실제 환자 파일을 외부에 보내지 않았다. 과거 승인된 30개 표본을 새로 재전송하지 않았다.
- 실제 공급사 파일 전수 지리 정확도, 전국 쉼터 완전성, 모든 기관의 운영 여부는 검증하지 않았다.
- 신규 시험은 합성 데이터이며 실제 연결 검사와 구분한다. 카카오·서울 데이터의 검색 제한은 앱 수정으로 해제되지 않는다.
- 인쇄 검사는 CSS 미리보기다. 전체 PDF 페이지 분할이나 로드뷰 영상의 PDF 포함을 새로 보장하지 않는다. 로드뷰는 원문 링크, 첨부사진은 출력에 포함하는 기존 방식을 유지한다.
- R-ONE·건축물·관광 등 변경하지 않은 API 전체의 실시간 전수 재조회는 수행하지 않았다.
