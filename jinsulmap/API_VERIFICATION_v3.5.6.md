# JINSUL MAP v3.5.6 — 관광공사 승인 후 응답 해석 수정

기록일: 2026-09-07

## 승인 및 원인
- 로그인된 공공데이터포털 활용신청 현황에서 관광공사 지역별 방문자수 서비스의 승인 상태를 확인했다. 개발계정, 신청일 2026-09-07, 만료예정일 2028-09-07.
- 사용자가 제공한 인증키 파일은 기존 PUBLIC_DATA_API_KEY와 동일하다. 키 교체나 원문 문서 업로드는 하지 않았다.
- 승인 후 HTTP 403이 해소되어 원본 응답 코드 0000을 수신했다. v3.5.5 공통 응답 해석기가 이 값을 오류로 처리해 표시가 막혔다.
- 관광공사 전용 scanVisitorEnvelope에서 0000과 body가 함께 있는 정상 응답만 공통 성공 형식으로 정규화한다. 다른 API의 성공·오류 판정은 변경하지 않는다.

## 검증
- 기존 회귀 테스트 34개 통과.
- 관광공사 전용 10개 검증 통과: 0000과 데이터 처리, 원본 불변, 오류 코드 거부, body 없는 응답 거부, 정상 빈 자료 처리, 기존 공통 해석기 동작 보존.
- 위 44개는 로컬/모의 검증이다. 운영 결과는 별도로 기록한다.
