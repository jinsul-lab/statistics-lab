# JINSUL MAP v3.5.3 검증

기록일: 2026-09-07

## 변경
- 검색 후보지 법정동 코드의 시도 식별자를 우선 사용하고, 주소·시도명으로 보완한다. 지역을 확인할 수 없으면 서울로 추정하지 않는다.
- 서울 실시간 인구와 공식상권의 브라우저 직접 호출을 서울 전용 HTTPS Worker POST 요청으로 변경했다.
- 전국 SGIS 기준연도 인구와 반경 상가 조회는 유지했다. 전국 실시간 유동인구를 새로 확보한 것은 아니다.
- 보고서에 검색 지역과 인구 데이터 공간 기준을 표시하고, 서울 밖 제공 대상 아님·반경 내 대상 없음·조회 불가·자료 없음·일부 연결을 구분했다.
- 점포 응답이 비어 있으면 실제 0곳으로 표시하지 않는다.
- 업로드, 통계 계산, 지도·로드뷰, 마커, 기존 필터와 외부 SDK를 보존했다.

## 운영 상태와 한계
- 서울 전용 Worker 생성 및 코드 배포 완료. Cloudflare 편집기에서 `3bba09a9 (Active) Latest`, 구문 진단 `No Problems` 확인.
- 주소: `https://jinsul-seoul-proxy.yms0127.workers.dev/seoul`.
- R-ONE과 별도 Worker이며 Git 저장소 자동 연결을 추가하지 않았다.
- 공개 health 주소 접속이 브라우저 도구에서 `net::ERR_BLOCKED_BY_CLIENT`로 차단되었다. 운영 CORS·실시간 인구·분기 유동인구·점포 실제 응답 성공을 확인하지 못했다.
- 현재 서울 분기 선택과 내장 매출 기준 시점은 기존 버전을 유지한다. 미제공 분기의 자료를 다른 시점 값으로 채우지 않는다.
- 기존 클라이언트 서울 키를 HTTPS POST 본문으로 중계한다. Worker 소스에 키를 넣지 않으며 상위 응답의 키 반사를 제거한다. 서울시 원본 요청은 기존 공식 HTTP:8088 경로를 사용하므로 전체 구간 HTTPS라고 설명하지 않는다.
- GitHub 업로드 및 Pages 배포 상태는 HANDOFF.md에 기록한다.
