# JINSUL MAP v3.5.4 검증

기록일: 2026-09-07

## 변경
- 서울 HTTPS 중계의 일시적 네트워크 오류·시간 초과·429/5xx를 1회 자동 재시도한다. 인증·요청 오류는 반복하지 않는다.
- 실패한 점포 조회 Promise 캐시를 제거하여 다음 조회에서 복구할 수 있다.
- 최근 완료 분기부터 최대 4개 분기를 확인하고 자료가 있는 분기를 선택한다. 통신 실패를 빈 자료로 오인하여 과거 분기로 넘기지 않는다.
- 유동인구의 시간대·요일·연령 상세를 기존 카드 안의 펼침 영역으로 추가했다. 누락 값은 자료 없음으로 표시한다.
- 시간대 자료가 없을 때 피크를 00~06시로 잘못 표시하던 문제를 수정했다.
- 고정 실행 주소 `/statistics-lab/jinsulmap/`에서 최신 버전으로 이동한다. 기존 버전 파일은 보존한다.

## 검증
- 로컬 회귀 34개, 지역 판별 10개, 서울 복구·세부 지표 10개, Worker 모의 검증 12개: 총 66개 통과.
- 문법, 기존 ID 212개·기존 함수·SDK·인증 설정 보존을 검사했다. 모든 기능의 실제 UI 조작을 완료했다는 뜻은 아니다.
- 운영 브라우저 검증 결과는 아래에 별도 기록한다.

## 범위와 참고
- 참고: [서울시 상권분석서비스](https://golmok.seoul.go.kr/owner/owner.do), [자료 출처](https://golmok.seoul.go.kr/source.do).
- 사이트의 인구 세부 비교 방식을 참고했다. 공식 서비스의 보행권·다각형 배분 계산을 복제한 것은 아니다.
- 분기 유동인구는 공식 상권 전체, 실시간 인구는 지정지점, SGIS는 행정구역이다. 후보지 원형 반경의 실측 유동인구로 표시하지 않는다.
- 전국 실시간 유동인구 신규 공급원을 확보한 것은 아니다. 서울 외 지역은 기존 SGIS·전국 반경 상가와 제공 범위 안내를 유지한다.
- 기존 매출 내장자료의 기준은 2025년 4분기이며 이번 변경에서 갱신하지 않았다.
- 서울 Worker 1.0.2 및 R-ONE Worker 배포는 변경하지 않았다.
- 사용자가 보고한 오류의 실행 URL은 아직 확인되지 않았다. 구버전 문구와 일치하지만 원인을 구버전으로 단정하지 않는다.

## 운영 브라우저 실제 확인
- 고정 주소에서 v3.5.4로 이동 후 왕십리본정형외과를 반경 1km로 새로 스캔했다.
- 왕십리역 실시간 추정 인구 18,000~20,000명, 원본 기준 2026-09-07 13:40.
- 행당시장상점가 유동인구 902,024명, 2026년 2분기. 이전 고정 분기 2026년 1분기 대신 최신 제공 분기가 선택됐다.
- 점포 323곳, 개업 10 / 폐업 13곳, 2026년 2분기.
- 상세 펼침 동작 및 실제 수치 확인: 00~06시 211,358명(23.4%), 토요일 135,298명(15.0%), 20대 201,636명(22.4%). 시간대 6개·요일 7개·연령 6개 모두 값 표시.
- 서울 세 항목에서 사용자가 보고한 브라우저 API 오류가 재현되지 않았다. 모든 환경에서 장애가 없음을 보장하지는 않는다.
- 비서울 지역 분기는 이번에 모의 검증했으며 실제 부산 스캔은 v3.5.3 보고서의 이전 확인 결과다.
