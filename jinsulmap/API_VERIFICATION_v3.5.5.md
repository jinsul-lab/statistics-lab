# JINSUL MAP v3.5.5 — 지연 복구·전국 방문인구·차트

## 변경 근거
- 기존 일반 API 요청은 15~22초 후 재시도 없이 종료됐다. 심평원 4개 진료과, 실거래 6개월 병렬 요청으로 동일 제공처 요청이 집중됐다.
- API 종류별 동시 요청을 2개로 제한하고 큐 대기 시간을 실제 전송 시간과 구분했다. 브라우저 전송·본문 수신 제한은 1차 최소 30초, 재시도 최소 45초다.
- 일시적 네트워크 오류, 408/429/5xx 및 원본 API의 지연 코드 05·초당 제한 23을 1회 재시도한다. 일일 한도·인증 오류는 반복하지 않는다.
- 검색 변경/취소 시 진행 중 fetch와 대기 요청을 취소한다. 세대가 지난 요청 결과와 진단값은 새 검색에 반영하지 않는다.
- 상세분석 종합 탭에 API별 요청·수신·재시도 수, 최대 응답 시간, 큐 대기 시간, 최근 상태를 추가했다. 인증키·전체 요청 URL·응답본문은 진단에 저장하지 않는다.
- HTTP 수신 성공은 자료 성공과 다르다. API 본문의 인증·자료 없음 상태는 각 데이터 카드에서 별도로 판정한다.

## 전국 방문인구
- [관광공사 공식 명세](https://www.data.go.kr/data/15101972/openapi.do)의 `locgoRegnVisitrDDList` 연결 추가. 검색 주소 법정코드 앞 5자리와 응답 `signguCode`·`baseYmd`가 일치하는 행만 사용한다.
- 기존 공공데이터 서비스키로 요청하며 해당 서비스의 활용승인이 없으면 오류를 표시한다. 가입·활용승인 상태를 임의로 가정하지 않는다.
- 최근 세 달의 말일 일별 관측을 비교한다. 월 합계·실시간·병원 반경 유동인구가 아니며 각 날짜와 원본 방문자 구분을 표시한다.
- 기존 SGIS 인구를 유동인구로 대체하지 않는다. 원형 반경 상가 집계와 서울 지정지점·공식상권 지표를 유지한다.
- 세종 등 API 코드 체계가 일치하지 않거나 자료가 없는 경우 0명이 아닌 자료 없음으로 표시한다. 전체 전국 수신을 확인하기 전에는 전국 연결 완료라고 보고하지 않는다.

## 시각화
- 기존 카드/탭 구조에 그라데이션, 강조선, 색상별 KPI, 툴팁, 둥근 막대 디자인 적용.
- 서울 시간대·요일·연령 상세를 숫자와 비중이 있는 비교 막대로 개선하고 인구 상세 탭에도 제공.
- 전국 방문인구 시계열 비교 카드 추가. 수치는 원본 분류별로 분리하고 임의로 합산하지 않는다.
- SGIS 미수신 시 차트에 0을 그리던 값을 null로 변경했다.
- 환자 업로드, 필터, 마커 색상, 로드뷰, 탐색 점수 계산식은 유지했다.

## 로컬 검증
- 회귀 34, 지역 10, 서울 분기/복구 10, 네트워크/전국 방문자 12, Worker 12: 총 78개 통과.
- 첫 전송 시간 초과 후 긴 재시도 성공, 본문 수신 중 시간 초과, 403 비재시도, 503 재시도, HTTP 200 안의 지연 오류, 동시성 상한, 진행/대기 요청 취소, 코드/날짜 필터, 윤년·연도 경계 검증.
- 모의 시간은 테스트용으로 축소했다. 실제 30초/45초 운영 응답 성능의 측정값과 혼동하지 않는다.

## 운영 제약
- 서울 Worker 원본 호출 제한은 기존 18초다. 이번 브라우저 변경으로 Worker 내부 제한까지 늘어난 것은 아니다. Worker 504도 브라우저 재시도 대상이다.
- 외부 서비스 장애·할당량·활용승인·CORS는 브라우저 대기 시간을 늘려도 해결되지 않을 수 있다.
- 기존 프록시 자동 배포 분리 유지. R-ONE 프록시 변경 없음.

## 운영 실측: 왕십리본정형외과 1km
2026-09-07 운영 브라우저에서 새로 스캔. 아래 수치는 API 종류별 개별 요청의 최대 시간이며 전체 스캔 시간이 아니다.

| API | 요청/수신 | 최대 응답 | 최대 큐 대기 |
|---|---|---|---|
| 심평원 | 4/4 | 23.1초 | 23.1초 |
| 서울 인구·상권 | 4/4 | 2.1초 | 1.1초 |
| R-ONE | 9/9 | 4.3초 | 7.4초 |
| SGIS | 4/4 | 0.2초 | 0.0초 |
| 전국 상가 | 3/3 | 0.4초 | 0.0초 |
| 건축물대장 | 1/1 | 0.1초 | 0.0초 |
| 실거래 | 6/6 | 0.1초 | 0.3초 |
| 전국 방문인구 | 1/0 | 0.1초 | 0.0초 |

- 재시도는 이 회차 모두 0회. 실제 지연 요청이 30초 안에 완료됐다. 1차 실패 후 복구는 별도 모의 테스트로 검증했다.
- 심평원 23.1초는 기존 18초 제한보다 길다. 4개 진료과 공식 고유 의원 26곳 수신을 확인했다.
- 전국 방문인구는 HTTP 403. 시간 초과가 아니며 활용승인/접근 권한 확인이 필요하다. 데이터를 성공 수신한 것으로 보고하지 않는다.
- 행당시장상점가 최신 유동인구와 시간대·요일·연령 수치, 실시간 왕십리역 18,000~20,000명 및 인구 상세 탭 표시 확인.
- 차트 화면을 스크린샷으로 검수했다. 최종 다열 상세 차트는 배포 후 재확인한다.

## 운영 실측: 부산 해운대구 중동 1km
- 카카오 경쟁 1곳, 심평원 공식 3곳(부분 성공), 전국 반경 상가 1,261곳, R-ONE 부산 > 해운대 수신.
- 서울 두 항목은 제공 지역 아님으로 표시했다.
- 심평원 전송 6회 / 수신 3회 / 재시도 2회, 최대 응답 22.0초, 최대 큐 대기 15.1초. 최초 실패 두 건 중 한 건은 재시도로 복구됐고 신경외과는 HTTP 504가 재시도 후에도 남았다.
- 이 실패는 브라우저 제한 도달이 아닌 서버 HTTP 504다. 0곳으로 계산하지 않으며 최종 버전의 범위 표에서도 일부 연결로 표시한다.
- SGIS 2/2 최대 0.1초, 실거래 6/6 최대 0.1초, 전국 상가 2/2 최대 0.3초. R-ONE은 같은 세션에서 이미 받은 표 캐시를 사용하여 새 네트워크 시간에 포함하지 않는다.
- 관광공사 방문인구는 부산에서도 HTTP 403. 전국 방문인구 실제 수신은 현재 미완료다.

## 취소 후 재검색
- 운영 화면에서 공식 API 처리 중 결과 지우기 실행 후 버튼이 다시 활성화되고 새 검색이 완료되는 것을 확인했다. 이전 결과가 새 검색을 덮어쓰지 않았다.
- 왕십리 재검색에서는 심평원 신경외과가 원본 코드 99를 반환했고 나머지 3개 진료과 25곳이 수신됐다. 첫 회차 26곳과의 차이는 부분 실패 때문이다. 두 결과를 모두 정상 전체 집계로 취급하지 않는다.
- 원본 API의 모든 불안정성이 제거됐다고 보고하지 않는다. HTTP 504·코드 99는 브라우저 대기시간 연장과 별도의 제공기관 오류다.
