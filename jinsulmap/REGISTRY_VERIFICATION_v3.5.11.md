# v3.5.11 입지자료 층·호실 대장 연결

2026-09-07

## 변경
- 입지자료 열기 시 후보 필지의 건축물대장 층별개요·전유공용면적 자동 조회. 100건씩 최대10페이지, 총건수 변경·필지 불일치·누락 응답 구분.
- 층별 용도·면적·구조·원본 생성일·조회일을 보고서에 자동 반영. 자료표 앞40건 표시 및 전체 수신 건수 별도 표기.
- 조회가 완결된 전유 호실을 선택하면 호실과 전유면적만 빈 입력란에 반영. 공용면적 제외. 층 전체·부분 임대·호실 전체를 구분하고 기존 입력값 보존.
- 대장 사실을 저장/JSON/단일 입지자료HTML에 보관. 원본 생성일은 최신 현장 확인일과 구분.
- 부천 샘플 필지에 한해 직접 찾은 중개법인 원문·연락처·기준층 면적 및 미확인 사항 표시. 전국 매물 실시간 연동이라고 주장하지 않음.

## 실제 데이터 확인
- 부천 원미구 중동1140-5(신흥로197): 표제부·층별개요 HTTP200/00 실제 응답.
- 삼성화재부천사옥: 지상13·지하3, 사용승인20030218, 주차 실내79+실외6=85, 승강기 승용1+비상1=2.
- 1층 층별개요561.73㎡·제2종근린생활시설. 제공 샘플100.49평(약332.20㎡)은 1층 일부 임대이므로 대장 층 면적으로 치환하지 않음.
- 원본 생성일20231230. 오늘 조회했다는 이유로2026년 현장 확인값으로 표시하지 않음.
- 국립중앙의료원 승인 후 실제 API HTTP200/00 확인. 용인 서울본정형외과 전화031-335-8888과 주소 대조, 운영앱 평일08:30~20:00·토08:30~14:00·평일휴게13:00~14:00 수신 확인(3.5.10에서 승인만으로 연결됨).
