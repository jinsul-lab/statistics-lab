# 무더위쉼터 지도·API 대조 및 개선 · v3.7.5

검증일: 2026-09-29 (KST). 고정 파일: `jinsulmap.html`.

## 결론

네이버뿐 아니라 카카오맵 웹에도 쉼터 목록이 있었다. 반면 카카오 Local 공개 API는 동일 검색어에서 0~1건만 반환했다. 공개 API 0건을 시설 부재로 해석하거나 경비실 검색만으로 쉼터를 대체하면 안 된다. 이번 표본만으로 네이버 전체 자료가 다른 원천보다 정확하다고 결론 내릴 수는 없다. 현재 개방 여부는 현장·시설 확인을 하지 않았다.

## 실제 API 및 공식자료

- 카카오 Local REST 5지역 × 4검색어 20회, 띄어쓰기·폭염쉼터 변형 10회, 웹과 정확히 동일한 검색어 5회: HTTP 200. 0건은 HTTP 연결 실패가 아니었다. API 제공 범위가 웹과 다른 이유를 특정 정책 조항으로 단정하지 않는다.
- 성동구 API의 1건은 `무더위쉼터 매봉경로당`, 주소 `서울 용산구 한남동 726-250`. 문자열 지역명만으로 행정구역이 제한되지 않았다.
- 부산 API 실제 반환 이름·카테고리 모두 `무더위,한파쉼터`를 포함했다. 기존 명칭/카테고리 필터에서 탈락하는 오류를 확인했다.
- 서울 공식 `TbGtnHwcwP`를 기존 승인키 및 서울 Worker로 실제 조회: HTTP 200, `INFO-000`, GitHub Pages Origin CORS 정상. 전체 5페이지 4,092건, 기준연도 2026, 좌표 누락 0·동일 복합ID 중복 0.
- 서울 전체 중 성동구 주소 206건. 왕십리 주변 사각형(남37.55·서127.02·북37.58·동127.05) 안 146건. 후자는 반경·성동구 전체가 아니라 명시한 사각형 범위이다. 캐시 재조회에 추가 API 호출 없음.
- [서울 공식 데이터/명세](https://data.seoul.go.kr/dataList/OA-21065/S/1/datasetView.do?tab=A), [카카오 Local 공식 명세](https://developers.kakao.com/docs/latest/ko/local/dev-guide#search-by-keyword).

## 적용 변경

1. 서울 지도 범위에서는 이름에 쉼터가 없는 은행·주민센터·도서관도 공식 지정 자료로 추가한다. 전체 페이지 완료본만 1시간 메모리 캐시, 페이지 병렬 최대 2개, 부분실패는 완료/0건으로 표시하지 않는다.
2. `무더위,한파쉼터`, `한파·무더위쉼터`, 폭염쉼터 명칭을 분류한다. 냉방쉼터를 노인시설로 일괄 판단하지 않는다. 관리·경비실은 기본 꺼짐인 보조 문의처를 유지한다.
3. API가 0건이어도 지도 중심 시군구를 자동 확인하여 네이버·카카오 웹 검색을 제공한다. 시군구 검색과 현재 지도 범위 검색의 차이를 안내하고 검색어를 수정할 수 있게 한다.
4. 개별 시설별 원문·네이버 대조·카카오 상세 링크, 공식 여부·기준연도·운영 안내·시설유형을 표시하고 시설/경로 Excel에 보존한다. 자동 대조가 이루어지지 않은 시설은 대조 미확인으로 남긴다.
5. 제공자별 ID를 구분하고 좌표로 지도 범위를 재검증한다. 출처 간 같은 시설이 중복될 수 있으므로 자료 건수라고 표시한다. 근거 없는 근접거리 합치기는 하지 않는다.
6. 환자 업로드·통계 계산·상권 통계는 변경하지 않았다. 기존 마커 색상·지도 도구·단일 HTML 고정 주소를 유지한다.

- 기존 병원 패널 1280/1024/768px, 마커 겹침·스크롤·Esc·늦은 응답 회귀 통과.

- 실제 브라우저/실제 API 검증은 위 항목에만 해당한다. 전국 원천 전체, 실제 환자 원본, PDF 출력은 이번 변경에서 재검증하지 않았다.

## 남은 범위

- 전국 공식 자동 수집은 [행정안전부 무더위쉼터 API](https://www.safetydata.go.kr/disaster-data/view?dataSn=1338)의 별도 활용신청·서비스키가 필요하다. 현재 서울 밖은 카카오 API와 양쪽 지도 웹 확인을 제공하며 전국 공식 연결 완료로 표시하지 않는다.
- 전국 공개 샘플은 최신 전체 데이터가 아니므로 앱에 전국 자료로 내장하지 않았다. 경기 후보 API는 서비스 없음 오류여서 연결하지 않았다.
- 카카오·네이버 웹 전체 목록을 비공개 호출로 가져오거나 공식 데이터로 저장하지 않았다. 실제 운영기간·현장 출입조건은 별도 확인이 필요하다.
